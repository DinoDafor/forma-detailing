# Аналитика FORMA

## Текущее состояние

Подготовлены интеграции Яндекс Метрики (включая карты кликов и Вебвизор), Google Analytics 4 и Google Ads. Номера кабинетов пока отсутствуют: все интеграции выключены, сторонние скрипты не загружаются, статистика никуда не отправляется. Без настроенных интеграций баннер и кнопка настроек скрыты.

Форма только составляет текст обращения. Событие `request_prepared` не означает полученную заявку. `generate_lead` и рекламная конверсия не вызываются текущей формой.

## Подключение

1. Создайте счётчик на https://metrika.yandex.ru/ для адреса сайта. В настройках разрешите Вебвизор, карты и аналитику форм, если нужны записи поведения. Укажите номер в `dist/analytics-config.js` → `yandexMetrikaId` (строкой из цифр). Для начала достаточно Метрики.
2. При необходимости создайте веб-поток GA4 и добавьте его `G-...` в `googleAnalyticsId`. Отключите автоматические расширенные события формы, прокрутки и внешних переходов, если хотите анализировать только события этого лендинга. Автоматическую запись просмотров при изменении истории также выключите: просмотр страницы отправляется нашим кодом один раз.
3. Для Google Ads задайте `googleAdsId` (`AW-...`) и метку действия-конверсии в `googleAdsLeadLabel`. Номера являются публичными идентификаторами; секреты и API-токены сюда не помещаются. Не подключайте параллельно второй экземпляр тех же тегов через GTM.
4. В Метрике создайте цели типа «JavaScript-событие» для нужных имён из таблицы ниже. Свяжите счётчик с Директом в рекламном кабинете. В GA4 отметьте необходимые события как ключевые; подготовку текста обращения не обозначайте как принятую заявку.
5. Опубликуйте конфигурацию и проверьте поступление данных в кабинетах после разрешения аналитики. Проверка событий в локальной консоли не подтверждает их получение сервисами. Блокировщики и отказ посетителя ограничивают статистику.

Для превращения формы в настоящую заявку сначала нужен обработчик отправки. Только после успешного ответа сервера вызывайте `FormaAnalytics.confirmLead(opaqueRequestId)`, где ID — технический идентификатор заявки без контактов. Повтор одного ID в пределах страницы отбрасывается. Для полной защиты от дублей после перезагрузки используйте серверную дедупликацию. Телефонные клики и переходы в мессенджер не подтверждают звонок или сообщение.

## События

| Событие | Когда | Параметры |
| --- | --- | --- |
| `page_view` | После разрешения аналитики | Очищенный адрес, источник, UTM |
| `section_view` | Блок появился в области просмотра | `section` |
| `navigation_click` | Переход по ссылке к блоку | `target`, `position` |
| `cta_click` | Кнопка подбора, переход к обращению, подготовка текста | `target`, `position` |
| `service_open` | Раскрытие описания услуги | `target`, `position` |
| `service_select` | Перенос выбранной услуги в форму | `service`, `position` |
| `goal_select` | Выбор задачи автомобиля | `goal`, `position` |
| `faq_open` | Раскрытие ответа | `target`, `position` |
| `form_start` | Первое изменение поля в течение просмотра | `position` |
| `form_error` | Ошибка проверки формы | `field`, `reason` |
| `request_prepared` | Составлен текст обращения | `service`, `position` |
| `contact_click` | Ссылка на телефон, email, Telegram или WhatsApp | `channel`, `position` |
| `outbound_click` | Внешняя HTTP-ссылка | Только домен и `position` |
| `scroll_depth` | Прокрутка 25, 50, 75, 90, 100% | `percent` |
| `engaged_time` | 15, 30, 60, 120 секунд в видимой вкладке | `seconds` |
| `session_end` | Страница закрывается или покидается, доставка не гарантирована | `seconds` |
| `generate_lead` | Только подтверждённый сервером результат будущей отправки | `position` |

Ссылок на телефон и мессенджеры в текущем макете нет. Обработчики готовы для будущих настоящих контактов. Просмотры, повторные визиты, устройства, источники и путь посетителя анализируются в кабинетах подключённых сервисов; отдельной панели на сайте нет. Склейка человека между разными устройствами и связь с CRM не настроены.

## Источники и выбор посетителя

После разрешения сохраняются первая и последняя рекламные метки внутри текущей вкладки (`sessionStorage`). Поддерживаются `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`. Имена кампаний должны быть короткими метками без личных данных; email, длинные цифровые значения и произвольные query-параметры исключаются из отправляемого адреса. Для рекламной атрибуции сохраняются в адресе технические `yclid`, `gclid`, `gbraid`, `wbraid`. Источник перехода передаётся только как origin, без пути и параметров. Возвращающихся посетителей определяют сами сервисы по своим идентификаторам.

Выбор «Разрешить»/«Отказаться» хранится на 180 дней в `localStorage`. До разрешения сторонние аналитические скрипты не загружаются и прошедшие действия не накапливаются для последующей отправки. Кнопка «Настройки аналитики» в подвале позволяет изменить выбор. При отзыве разрешения страница перезагружается для остановки уже загруженных сторонних обработчиков; история, ранее переданная сервисам, не удаляется, их существующие cookie автоматически не очищаются.

Значения автомобиля и свободного текста не входят в события. Поля помечены `ym-disable-keys`, результат — `ym-hide-content`, у формы отключено автоматическое событие отправки Метрики. Вебвизор записывает остальную страницу только при разрешённой аналитике. Для действующего бизнеса дополните сайт его контактами и документами о фактически используемых сервисах и обработке данных.

## Проверка без кабинетов

В консоли браузера:

```js
FormaAnalytics.status();
FormaAnalytics.setDebug(true);
// Выполните действия на странице.
FormaAnalytics.getEvents();
```

Отладка хранит последние 100 событий только в памяти текущей страницы; без настроенных счётчиков `sent` всегда `false`. Перезагрузка удаляет журнал. Она не включает сторонние скрипты, не отменяет выбор посетителя и не создаёт фиктивную статистику.

```powershell
node --test tests/analytics.test.mjs
```

Официальные источники для интеграций: [инициализация Метрики](https://yandex.ru/support/metrica/ru/code/counter-initialize), [reachGoal](https://yandex.ru/support/metrica/ru/objects/reachgoal.html), [исключение содержимого из записи](https://yandex.ru/support/metrica/ru/code/html-markup), [Google consent](https://developers.google.com/tag-platform/security/guides/consent), [Google tag API](https://developers.google.com/tag-platform/gtagjs/reference).
